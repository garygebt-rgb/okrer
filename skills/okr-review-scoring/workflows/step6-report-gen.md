# Step 6: 报告生成

**输入:** Step 1-5 所有输出（材料、验证数据、证据、评分、文档分析）

## 执行步骤

### 1. 编译评审报告

使用模板 `~/.claude/skills/okr-review-scoring/templates/review-report-template.md` 生成完整评审报告，包含以下部分：

1. **报告头** — 员工姓名、季度、岗位、评审日期
2. **评分结果** — 难度、努力度、完成度、总分（含明细）
3. **证据清单** — 所有已验证证据的可访问性和相关度
4. **优势与不足** — 基于全部数据的 LLM 评估
5. **往期对比** — 当前季度 vs 上一季度（如有数据）
6. **下季度建议** — 具体可操作的改进建议

### 2. 预览报告

将完整报告预览给用户审核。

### 3. 用户确认（3 选 1）

- **确认保存**: 将报告保存至 `~/.claude/skills/okr-review-scoring/reports/{userId}-{quarter}.md`
  - 显示保存确认消息
- **修改**: 允许用户提出具体修改意见，重新生成报告
- **取消**: 不保存退出，显示退出消息

## 输出格式

```
## 评审报告预览

[完整报告内容 — 使用模板结构]

---

请选择操作：
1. **确认保存** — 将报告保存至 reports 目录
2. **修改** — 输入需要修改的内容
3. **取消** — 退出评审流程
```

保存确认后：
```
评审报告已保存至 `reports/{userId}-{quarter}.md`。
总分: XX/100（难度 XX，努力度 XX，完成度 XX）。
此为建议评分，最终评分由人类评审决定。

okr-review-scoring 工作流完成。如需再次评审，重新运行此 Skill。
```

## 安全说明

- 报告包含敏感的绩效数据 — 仅保存到本地目录
- 所有评分明确标注为"建议评分 — 最终评分由人类评审决定"
- 报告包含免责声明："本评分报告由系统自动生成，仅供参考，不构成最终绩效评价"

## 错误处理

- **报告生成失败**: 显示错误，建议手动创建报告
- **文件保存失败**: 显示内容供用户手动复制粘贴
- **用户选择"修改"**: 循环重新生成，应用指定修改

## 数据类型引用

- 所有前序步骤的数据类型
- `JobCategory` from `okr-types.ts`
