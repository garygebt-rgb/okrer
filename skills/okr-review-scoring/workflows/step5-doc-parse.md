# Step 5: 自述文档解析

**输入:** Step 1 解析的自述文档，Step 2 验证数据，Step 3 证据匹配结果，Step 4 评分结果

## 执行步骤

### 5.1 深度内容分析

1. 分析执行摘要完整性：
   - 是否覆盖了季度初设定的所有 OKR？
   - 关键成就是否清晰表述？
   - 是否诚实承认了不足之处？

2. 交叉验证自述声称与系统数据（Step 2）：
   - 对每项声称的成就，对比 OKR 系统实际 score
   - 标记夸大项（声称 > 实际）
   - 标记保守项（声称 < 实际 — 用户可能谦虚）

3. 识别差距：
   - 未被自述提及的 OKR
   - 无支撑证据的声称
   - 自述与系统数据的差异

### 5.2 截图分析

对自述文档中的每张截图：
- 使用 Claude 视觉能力分析截图内容
- 提取：展示内容、可操作数据点、证据类型
- 评估：是否可作为证据？（置信度评分 0-1）
- 如截图模糊或不可用，标记为"无法解析，需要人工查看"

### 5.3 叙事与证据差距分析

1. 对比自述声称与已收集证据：
   - 有强证据支撑的声称
   - 证据薄弱或缺失的声称
   - 有证据但自述未提及的成就

2. 生成差距分析：
   - 过度表述区域（大量自述，少量证据）
   - 不足表述区域（强证据，少量自述）

3. LLM 评估叙事诚实度和完整性

## 输出格式

```
## 自述文档解析完成

### 深度分析
| 分析维度 | 发现 |
|----------|------|
| 执行摘要完整性 | 完整/部分/缺失 |
| 声称 vs 实际一致性 | X 处一致, Y 处夸大, Z 处保守 |
| 叙事空白 | N 个 OKR 未提及 |
| 截图可用性 | X/Y 张可用 |
| 总体诚实度 | 高/中/低 |

### 差距分析
| # | 类型 | 描述 |
|---|------|------|
| 1 | 夸大 | [具体描述] |
| 2 | 遗漏 | [具体描述] |
| 3 | 不足表述 | [具体描述] |
```

## 数据类型引用

- `ScreenshotAnalysis` from `screenshot-parser.ts`
- `ParsedNarrativeDoc` from `doc-parser.ts`
- `KeyResult` from `okr-types.ts`

## 安全说明

- 截图分析仅限于专业内容（不提取个人数据）
- 差距分析以中性方式呈现 — 不作为指控

## 错误处理

- **Claude 视觉分析失败**: 标记为"无法解析，需要人工查看"
- **自述内容极少**: 注明"自述内容较少，建议补充详细说明"
- **无差异发现**: 注明"自述内容与系统数据一致"

## 继续提示

> 自述文档解析完成。发现 X 处声称与实际一致，Y 处差异。Z 张截图中 W 张可用。输入"继续"进入下一步：报告生成。
