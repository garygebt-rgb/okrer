# Step 5: 用户确认

**目标：** 向用户展示完整的 OKR 目标设定分析结果（包含 Step 1-4 的所有输出），获取用户明确确认后再保存目标。

**前置条件：** Step 4（修改建议）已完成

**下一步：** 无 -- 本步骤为工作流终点

## 输入

- **Step 1 背景分析：** 历史周期数、未完成目标、重复目标、平均得分、设定习惯、岗位类型
- **Step 2 SMART 验证：** 5 维度结果汇总表、各维度详细分析、SMART 评分（X/5）
- **Step 3 对齐检查：** 贡献型对齐列表、依赖型对齐列表、未覆盖上级目标
- **Step 4 修改建议：** SMART 改进建议表、对齐改进建议、综合建议
- **用户草稿 Objective 的标题和描述：** 用户最初输入的 OKR 目标

## 执行步骤

### 1. 整理完整输出

将 Step 1-4 的所有输出整合为一份完整的分析报告，按以下顺序展示：

### 2. 展示原始目标

```
## 原始目标

**标题：** {用户草稿 Objective 的标题}

**描述：** {用户草稿 Objective 的描述}
```

### 3. 展示背景分析（Step 1 摘要）

```
## 背景分析

| 指标 | 值 |
|------|-----|
| 历史周期数 | {completedCycles.length} |
| 未完成目标数 | {incompleteObjectives.length} |
| 重复目标数 | {repeatedObjectives.length} |
| 平均得分 | {averageScore.toFixed(2)} |
| 设定习惯 | {tendency} |
| 岗位类型 | {jobCategory} |
```

如有未完成目标或重复目标，附加简要说明。

### 4. 展示 SMART 验证（Step 2 摘要）

```
## SMART验证

| 维度 | 结果 | 简要说明 |
|------|------|----------|
| Specific（具体性） | {通过/问题/建议} | {一句话说明} |
| Measurable（可衡量性） | {通过/问题/建议} | {一句话说明} |
| Achievable（可实现性） | {通过/问题/建议} | {一句话说明} |
| Relevant（相关性） | {通过/问题/建议} | {一句话说明} |
| Time-bound（时限性） | {通过/问题/建议} | {一句话说明} |

**SMART 评分：{score}/5**
```

### 5. 展示对齐检查（Step 3 摘要）

```
## 对齐检查

| 对齐类型 | 数量 | 涉及目标 |
|---------|------|---------|
| 贡献型对齐 | {contributingCount} | {目标列表} |
| 依赖型对齐 | {dependentCount} | {目标列表} |
| 未覆盖上级 | {uncoveredCount} | {目标列表} |
```

### 6. 展示修改建议（Step 4 摘要）

```
## 修改建议

### SMART改进建议
（列出 Step 4 生成的 SMART 改进建议表）

### 对齐改进建议
（列出 Step 4 生成的对齐改进建议）

### 综合建议
（列出 Step 4 生成的基于历史模式的综合建议）
```

### 7. 展示建议目标

基于所有修改建议，生成一份改进后的完整目标文本：

```
## 建议目标

**标题：** {改进后的 Objective 标题}

**描述：** {改进后的 Objective 描述（已整合所有 SMART 和对齐改进建议）}
```

### 8. 用户确认选择

向用户展示以下确认提示：

```
以上为完整的 OKR 目标设定分析结果。请选择：

1. **确认保存** — 将本次 SMART 分析和修改建议保存至本地，作为本季度 OKR 设定的参考
2. **修改** — 告诉我你要改哪个 Objective 或 KR，我帮你改写文字并输出修改后的版本
3. **确认保存并更新我的OKR** — 保存本地分析后，直接修订飞书线上的 OKR 内容
4. **取消** — 放弃本次设定
```

### 9. 处理用户选择

#### 9.1 用户选择"确认保存"（选项 1）

将本次完整的分析报告（含 SMART 评分、对齐检查、修改建议、建议目标）保存至本地文件：

```
## 已确认保存

OKR 目标设定分析已保存至本地：
  `~/.claude/skills/okr-goal-setting/analyses/{cycle_name}_{date}.md`

**SMART评分: {score}/5**

如需后续调整，可随时使用 okr-goal-setting 重新设定。
```

工作流结束。

#### 9.2 用户选择"修改"（选项 2）

```
已收到你的修改请求。请告诉我你要改哪个 Objective 或 KR（例如"O2 改写一下"或"KR3 时间改到5月底"），我帮你改写并输出修改后的版本。

注意：修改仅输出文字建议，不会直接更新飞书 OKR 系统。
```

- 等待用户指定要修改的目标
- 输出修改后的文字版本
- 修改完成后可再次进入确认流程

#### 9.3 用户选择"确认保存并更新我的OKR"（选项 3）

**第一步：保存本地**

将本次完整的分析报告保存至本地文件（同选项 1）。

**第二步：更新飞书线上 OKR**

> 此操作需要飞书 OKR 写入权限。在 OpenClaw（飞书智能伙伴）环境下，通过飞书 OKR API 直接更新目标内容。在 Claude Code 环境下，如 lark-cli 不支持写入，则提供更新指引。

```
正在更新飞书线上 OKR 内容...

## 更新结果

| 目标 | 状态 | 说明 |
|------|------|------|
| O1 | ✅ 已更新 | 标题和描述已更新 |
| O2 | ✅ 已更新 | 标题和描述已更新 |
| O3 | ✅ 已更新 | 标题和描述已更新 |

本地分析已保存。飞书线上 OKR 已按建议目标更新完成。
```

**更新失败时的降级处理：** 如 API 写入失败，保存本地分析报告并提示用户手动在飞书中更新。

#### 9.4 用户选择"取消"（选项 4）

```
已取消 OKR 目标设定。

如需重新开始，请再次调用 okr-goal-setting Skill。
```

工作流结束。

### 10. 无效输入处理

如果用户输入不是上述选项中的任何一个：

```
请输入以下选项之一：
1. **确认保存** — 保存分析至本地参考
2. **修改** — 指定要改的 Objective 或 KR
3. **确认保存并更新我的OKR** — 保存本地并更新飞书线上 OKR
4. **取消** — 放弃本次设定
```

重复步骤 8 的确认提示。

## 数据类型引用

本步骤使用以下 `okr-shared` 类型：

- `Objective` -- 目标结构（来自 `okr-types.ts`）
- `SmartDimension` -- SMART 5 维度枚举（来自 `okr-types.ts`）
- `AlignmentType` -- 对齐类型枚举（来自 `okr-types.ts`）
- `PreviousOKRAnalysis` -- 历史分析数据（来自 `okr-types.ts`）

## 安全注意

- **T-02-07（防篡改）：** 用户必须显式选择确认选项才保存目标，不设默认值，不设超时自动保存
- **T-02-08（可追溯）：** 所有建议均明确标注为"建议"，用户有最终决策权
- 更新操作仅写入用户有权限的飞书 OKR 系统，不修改他人数据
- 更新前必须展示完整建议目标供用户确认
