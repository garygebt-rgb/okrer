# OKR Review Scoring

实现期末OKR评审评分，解析用户自述文档(含截图)，验证证据，计算评分，生成评审报告。不计算完整KPI评分，只提供评分建议供人类参考。

## When to Use

USE this skill when:
- 期末评审OKR完成情况，收集用户自述文档和案例链接
- 自动化采集飞书会议/文档/聊天/Git/任务数据进行验证
- 验证证据链接有效性(可访问性、创建者、时间范围、关键词相关性)
- 计算评分: 难度40% + 努力度40% + 完成度20%，按岗位权重
- 解析用户自述文档中的非结构化内容(文字、表格、截图、OKR卡片)
- 生成评审报告: 评分结果、证据清单、优势不足、往期对比、下季度建议

## When NOT to Use

DON'T use this skill when:
- 过程跟进提醒 (使用 okr-process-tracking Skill)
- 设定新OKR目标 (使用 okr-goal-setting Skill)
- 查看他人OKR评审 (仅处理用户自己的数据)

---

## Workflow Overview

本工作流采用用户主动逐步执行模式。每步完成后询问"是否继续下一步？"

| Step | Name | Description |
|------|------|-------------|
| 1 | 材料收集 | 获取用户自述文档、案例链接、达成情况自述 |
| 2 | 数据验证 | 自动采集飞书会议/文档/聊天/Git/任务数据 |
| 3 | 证据匹配 | 验证链接可访问性、创建者、时间、关键词、一致性 |
| 4 | 评分计算 | 应用难度40%+努力度40%+完成度20%公式 |
| 5 | 自述文档解析 | 深度解析非结构化文档，截图识别，叙事与证据对比 |
| 6 | 报告生成 | 输出评分结果、证据清单、优势不足、往期对比、建议 |

## Step 1: 材料收集 (Material Collect)

获取用户自述文档链接、案例链接、达成情况自述。

### 输入

用户提供:
- 自述文档链接 (飞书文档URL)
- 案例链接 (可选，多个)
- 达成情况补充说明 (可选)

### 文档验证

```
验证飞书文档链接 → 检查文档访问权限
获取文档基本信息 → 提取标题、创建者、更新时间
```

### 输出

```
## 材料收集结果

| 材料 | 类型 | 状态 |
|------|------|------|
| 自述文档 | 飞书文档 | 已获取 |
| 案例1 | {类型} | {状态} |
| 案例2 | {类型} | {状态} |

文档标题: {docTitle}
文档创建者: {creator}
文档更新时间: {updatedAt}
```

完成后询问: "是否继续到 Step 2 (数据验证)？"

## Step 2: 数据验证 (Data Validate)

自动采集飞书会议/文档/聊天/Git/任务数据，验证证据来源。

### 数据来源

| 数据源 | 内容 | 用途 |
|--------|------|------|
| 飞书会议 | 会议记录、参会人员 | 协作证据 |
| 飞书文档 | 文档创建/编辑记录 | 工作产出 |
| 飞书聊天 | 相关讨论记录 | 沟通证据 |
| Git提交 | 代码提交记录 | 技术产出 |
| 飞书任务 | 任务完成记录 | 执行证据 |

### 采集方式

```
获取飞书文档编辑记录 → 调用飞书文档历史接口
获取飞书会议记录 → 调用飞书会议接口
获取Git提交记录 → 调用Git日志或飞书代码库接口
```

### 时间范围

采集周期起止时间范围内的数据。

### 输出

```
## 数据验证结果

| 数据源 | 记录数 | 时间范围 |
|--------|--------|---------|
| 飞书文档 | {n} | {start} - {end} |
| 飞书会议 | {n} | {start} - {end} |
| Git提交 | {n} | {start} - {end} |
...

数据采集完成时间: {timestamp}
```

完成后询问: "是否继续到 Step 3 (证据匹配)？"

---

## Step 3: 证据匹配 (Evidence Match)

验证链接有效性，5维度匹配检查。

### 5维度匹配

| 维度 | 检查内容 | 判断标准 |
|------|----------|----------|
| 可访问性 | URL是否有效 | 能成功获取内容 |
| 创建者 | 是否用户创建或参与 | 用户名出现在创建/编辑列表 |
| 时间范围 | 是否在周期内 | 创建/更新时间在周期范围内 |
| 关键词相关性 | 是否与KR相关 | 内容包含KR关键词 |
| 数据一致性 | 是否与自述一致 | 自述描述与实际数据匹配 |

### 匹配结果

| 证据 | 可访问 | 创建者 | 时间 | 关键词 | 一致性 | 总评 |
|------|--------|--------|------|--------|--------|------|
| 文档A | 通过 | 通过 | 通过 | 通过 | 通过 | 强匹配 |
| 会议B | 通过 | 通过 | 通过 | 问题 | - | 弱匹配 |
| 链接C | 失败 | - | - | - | - | 无效 |

### 输出

```
## 证据匹配结果

强匹配证据数: {strongMatchCount}
弱匹配证据数: {weakMatchCount}
无效证据数: {invalidCount}

### 无效/弱匹配证据说明
{具体问题和建议}
```

完成后询问: "是否继续到 Step 4 (评分计算)？"

## Step 4: 评分计算 (Score Calc)

应用难度40% + 努力度40% + 完成度20%公式，按岗位权重计算。

### 评分维度

| 维度 | 权重 | 评估方式 |
|------|------|----------|
| 难度 | 40% | LLM综合评估(技术复杂度/资源投入/时间压力/创新性/跨部门协作) |
| 努力度 | 40% | 客观证据(证据数量/更新频率/Git活跃度) |
| 完成度 | 20% | 飞书OKR系统KR最终score值(0-1范围) |

### 难度评估

LLM综合判断5个因素:
1. 技术复杂度: 是否涉及新技术、架构改造
2. 资源投入: 团队规模、预算支持
3. 时间压力: 是否有紧迫截止日期
4. 创新性: 是否首创或突破性工作
5. 跨部门协作: 是否涉及多团队协调

评分: 0-1分

### 努力度评估

客观证据统计:
1. 证据数量: 强匹配证据总数
2. 更新频率: OKR备注更新次数
3. Git活跃度: 提交数量(如有)

评分: 0-1分

### 完成度评估

直接取飞书OKR系统KR最终score值。

评分: 0-1分

### 总分计算

```
总分 = 难度 x 0.4 + 努力度 x 0.4 + 完成度 x 0.2
```

### 岗位权重

不同岗位可调整权重系数:

| 岗位 | 难度系数 | 努力度系数 | 完成度系数 |
|------|----------|-----------|-----------|
| 研发 | 1.0 | 1.0 | 1.0 |
| 产品 | 0.9 | 1.1 | 1.0 |
| 测试 | 1.0 | 1.0 | 1.0 |
| 管理 | 0.8 | 1.2 | 1.0 |

### 输出

```
## 评分计算结果

| Objective | 难度 | 努力度 | 完成度 | 总分 |
|-----------|------|--------|--------|------|
| O1 | {d} | {e} | {c} | {total} |
| O2 | {d} | {e} | {c} | {total} |
...

周期总分: {cycleTotal}

评分说明: 所有评分均为建议评分，最终评分由人类评审决定。
```

完成后询问: "是否继续到 Step 5 (自述文档解析)？"

---

## Step 5: 自述文档解析 (Doc Parse)

深度解析非结构化文档，截图识别，叙事与证据对比分析。

### 文档内容解析

解析内容类型:
- 文字段落: 提取关键叙述
- 表格数据: 提取数据内容
- 截图图片: OCR识别文字内容
- OKR卡片: 提取目标/KR信息

### 截图处理

```
识别截图内容 → 图像OCR识别
提取关键文字 → 文字内容提取
关联对应KR → 内容与KR匹配
```

### 叙事与证据对比

对比用户自述与客观证据:
- 自述声称已完成 → 证据是否支持
- 自述描述过程 → 是否有过程记录
- 自述提及成果 → 是否有产出证据

### 一致性分析

| 自述内容 | 证据支撑 | 一致性 | 说明 |
|----------|----------|--------|------|
| 完成X功能 | 有提交记录 | 一致 | 证据充分 |
| 主导Y项目 | 无相关记录 | 不一致 | 建议补充证据 |

### 输出

```
## 自述文档解析结果

### 关键叙事提取
{用户自述关键内容摘要}

### 截图识别结果
{截图内容和关联KR}

### 叙事与证据对比
{一致性分析表}
```

完成后询问: "是否继续到 Step 6 (报告生成)？"


## Scoring System

评分体系说明:

| 维度 | 权重 | 说明 |
|------|------|------|
| 难度 | 40% | LLM综合评估技术/资源/时间/创新/协作5因素 |
| 努力度 | 40% | 客观证据统计(证据数量/更新频率/活跃度) |
| 完成度 | 20% | 飞书OKR系统KR最终score值 |

总分 = 难度x0.4 + 努力度x0.4 + 完成度x0.2

重要: 所有评分均为建议评分，最终评分由人类评审决定。
