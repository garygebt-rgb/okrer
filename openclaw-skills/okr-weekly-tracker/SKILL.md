# OKR Weekly Tracker

员工自助安装的OKR周报自动化工具。安装后执行一次 `init` 命令，系统自动建立定时任务，每周扫描飞书活动、关联OKR进展、生成周报、尝试更新OKR、发邮件给PMO。全程自动化，无需每周手动触发。

## ⚠️ 安装检测与飞书CLI备用方案

### 飞书CLI安装检测

**执行 init 命令前必须检测飞书CLI是否已安装：**

```bash
lark-cli --version
```

**如果未安装，引导用户安装：**

```
检测到飞书CLI未安装，需要先安装才能获取OKR和飞书活动数据。

安装步骤：
1. npm install -g @larksuite/cli
2. npx skills add larksuite/cli -y -g
3. lark-cli config init --new
4. lark-cli auth login --recommend

安装完成后重新运行 init 命令。
```

### 数据获取策略：优先飞书智能伙伴，备用飞书CLI

| 数据类型 | 优先策略 | 备用策略（lark-cli） |
|----------|----------|----------------------|
| OKR周期/目标/KR | 飞书智能伙伴自动获取 | `lark-cli okr cycle-list/detail` |
| 飞书文档 | 飞书智能伙伴自动搜索 | `lark-cli docs +search +fetch` |
| 会议纪要 | 飞书智能伙伴自动搜索 | `lark-cli minutes +search` |
| 聊天记录 | 飞书智能伙伴自动搜索 | `lark-cli im +messages-search` |
| 发送邮件 | 飞书智能伙伴自动发送 | `lark-cli mail +send` |

## When to Use

USE this skill when:
- 作为员工，想要自动跟踪自己的OKR进展，不想每周手动写周报
- 想要本周飞书活动（文档、会议、聊天）自动关联到OKR目标
- 想要周报自动沉淀，OKR进展自动更新（如果可行）
- 想要周报概要自动发邮件给 ITPMO@homeinns.com
- 只需执行一次 init，后续全自动运行

## When NOT to Use

DON'T use this skill when:
- 想要手动控制每周周报内容（使用手动周报功能）
- 想要查看他人OKR进展（仅处理自己的数据）
- 想要期末评审评分（使用 okr-review-scoring Skill）
- 想要设定新OKR目标（使用 okr-goal-setting Skill）

每周五17:00，系统自动执行以下流程：

### Phase 1: 扫描本周飞书活动

自动扫描本周（周一至周五）用户在飞书中的所有活动：

| 数据源 | 扫描内容 | 关联方式 |
|--------|----------|----------|
| 飞书文档 | 用户创建/编辑的文档 | 标题关键词匹配OKR目标 |
| 飞书会议 | 用户参与的会议纪要 | 会议主题关键词匹配 |
| 群聊消息 | 用户发送的消息 | 消息内容关键词匹配 |
| 私聊消息 | 与同事的讨论记录 | 消息内容关键词匹配 |

### 扫描命令示例

飞书智能伙伴环境下：

```
扫描本周飞书活动 → 自动调用飞书搜索API

文档扫描:
请搜索本周我创建或编辑的飞书文档，返回 title, url, update_time, content_summary。
按关键词匹配我的OKR目标，返回匹配结果。

会议扫描:
请搜索本周我参与的会议纪要，返回 meeting_title, minute_token, participants, key_topics。
按关键词匹配我的OKR目标，返回匹配结果。

聊天扫描:
请搜索本周我发送的群聊和私聊消息（关键词: 项目、目标、进展），返回 chat_name, message_content, timestamp。
按关键词匹配我的OKR目标，返回匹配结果。
```

### Phase 2: 关联OKR进展（改进版）

将扫描结果与用户的OKR目标/KR进行关键词匹配，**增加置信度评分和人工校验**：

| KR | 关键词 | 匹配活动 | 置信度 | 进展推断 |
|----|--------|----------|--------|----------|
| KR1: 完成XX功能开发 | XX功能, 开发, 代码 | 文档A, 会议B, 提交C | 高(90%) | 有进展 |
| KR2: 优化YY性能 | YY, 性能, 优化 | 会议D, 聊天记录E | 中(70%) | 有进展 |
| KR3: 协调ZZ项目 | ZZ, 协调, 项目 | 会议F, 群聊G | 低(50%) | 待核实 |

### 关联算法（改进版）

```
对于每个KR:
  1. 提取KR标题关键词（名词+动词组合）
  2. 搜索本周活动是否包含关键词
  3. 计算匹配度：
     - 完全匹配关键词 = 权重1.0
     - 部分匹配关键词 = 权重0.5
     - 上下文相关但未直接匹配 = 权重0.3
  4. 计算置信度：
     置信度 = Σ(匹配活动权重) / KR关键词数量
     - 置信度>=0.8 → 高置信度，直接标记进展
     - 置信度0.5-0.8 → 中置信度，标记进展但提示确认
     - 置信度<0.5 → 低置信度，标记"待核实"
  5. 判断进展状态（5级）：
     - 有显著进展: 匹配活动>=3 且 置信度>=0.8
     - 有进展: 匹配活动>=1 且 置信度>=0.5
     - 待核实: 置信度<0.5（可能误匹配）
     - 未更新: 本周无任何活动记录（区分于"无进展")
     - 无进展检测: KR本周未在周报中提及（数据源未覆盖）
```

### 进展状态定义（5级）

| 状态 | 标识 | 判断标准 | 输出处理 |
|------|------|----------|----------|
| 有显著进展 | ✅✅ | 匹配活动>=3 且 置信度>=0.8 | 直接标记，无需确认 |
| 有进展 | ✅ | 匹配活动>=1 且 置信度>=0.5 | 标记并提示确认 |
| 待核实 | ⚠️ | 置信度<0.5（可能误匹配） | 标记并提示人工确认 |
| 未更新 | 🔸 | 本周无任何飞书活动 | 提示用户手动补充进展 |
| 无进展检测 | ❓ | KR不在周报追踪范围 | 标记数据源未覆盖 |

### 低置信度活动的人工校验

当置信度<0.5时，周报输出会增加校验提示：

```
⚠️ 待核实进展（置信度较低，请人工确认）：

| KR | 匹配活动 | 匹配关键词 | 置信度 | 建议 |
|----|----------|-----------|--------|------|
| KR3: 协调ZZ项目 | 会议F(主题含"ZZ") | ZZ(部分匹配) | 50% | 请确认是否与KR相关 |

回复"确认"标记为有进展，回复"取消"标记为无进展，回复"修改"调整匹配。
```

### 隐私保护机制（私聊消息扫描）

**私聊消息搜索增加隐私保护：**

```
私聊消息搜索范围限制：
- 仅搜索用户自己发送的消息（不搜索对方消息）
- 仅搜索包含OKR关键词的消息（不搜索私人内容）
- 不输出完整消息内容（仅输出关键词匹配摘要）
- 标记隐私级别：低(工作讨论)、中(项目相关)、高(私人内容-跳过)

搜索命令：
请搜索本周我发送的私聊消息，关键词包含我的OKR关键词。
返回 chat_partner_name, keyword_matched, message_summary(≤20字), privacy_level。
仅返回 privacy_level="低"或"中"的消息，跳过"高"级别。
```

## 定时任务管理

### 查看任务状态

用户可随时查看定时任务状态：

```
/okr-weekly-status
```

输出：
```
## OKR周报跟踪状态

定时任务: 运行中
下次执行: 2026-05-02 17:00
上次执行: 2026-04-25 17:00
上周周报: 已生成 ✓
邮件发送: 已发送 ✓
OKR更新: 2/3 成功
```

### 暂停/恢复任务

```
/okr-weekly-pause    # 暂停定时任务
/okr-weekly-resume   # 恢复定时任务
```

### 停止跟踪

```
/okr-weekly-stop     # 停止跟踪并清除配置
```

## 飞书API调用

### 所需权限

| 权限 | 用途 |
|------|------|
| `okr:okr.period:readonly` | 读取OKR周期 |
| `okr:okr.content:readonly` | 读取OKR目标/KR |
| `okr:okr.progress:write` | 写入KR进展备注（可选） |
| `docs:document:readonly` | 搜索飞书文档 |
| `vc:minute:readonly` | 搜索会议纪要 |
| `im:message:readonly` | 搜索聊天记录 |
| `mail:send` | 发送邮件 |

### API调用示例

飞书智能伙伴环境下自然语言调用：

```
# 文档搜索
请搜索本周我创建或编辑的飞书文档，返回 title, url, update_time

# 会议纪要搜索
请搜索本周我参与的会议纪要，返回 meeting_title, minute_token, key_topics

# 聊天记录搜索
请搜索本周我发送的群聊消息，关键词包含我的OKR目标，返回 chat_name, message_content

# OKR进展写入（如果支持）
请更新我的KR进展备注，KR-ID为xxx，备注内容为xxx

# 邮件发送
请发送邮件给 ITPMO@homeinns.com，主题为【OKR周报】xxx，正文为xxx
```
