## Problem

用户希望飞书云端的智能伙伴（openclaw/小龙虾）能直接使用 OKRskill 的三个技能（目标设定、过程跟进、评审评分）。需要评估：
1. 当前 Skills 的描述和工作流文件是否可直接被 openclaw 使用
2. openclaw 是否能从 GitHub 下载安装并运行
3. 需要做哪些改造（如：lark-cli 在 openclaw 环境的可用性、认证方式、执行权限等）

关键差异：
- Claude Code Skills 是为 Claude Code CLI 设计的，依赖 `~/.claude/skills/` 目录结构
- openclaw 是飞书云端的 AI 伙伴，可能有不同的 Skill/插件机制
- lark-cli 在 openclaw 环境中是否可用需要确认
- 认证（lark-cli auth login）在云端环境可能需要不同的授权方式

## Solution

1. 调研 openclaw 的技能/插件机制，确认如何部署 Claude Code Skills
2. 评估 lark-cli 在 openclaw 环境的可用性
3. 列出改造清单（SKILL.md 格式适配、认证适配、执行环境适配等）
4. 如果 openclaw 支持从 GitHub 拉取，确认仓库结构是否满足其要求
