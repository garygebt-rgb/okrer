## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | fetchCycleDetail | mitigate | Query only the authenticated user's own OKR data using their userId; never query other users' data without explicit authorization |
| T-03-02 | Spoofing | lark-cli im +messages-send | mitigate | Use bot identity for official notifications; preview messages before sending (lark-im safety rule requires user confirmation) |
| T-03-03 | Tampering | Local snapshot JSON files | mitigate | Store in user's home directory (~/.claude/skills/) with no shared write access; validate snapshot schema on load |
| T-03-04 | Tampering | Message delivery to wrong recipient | mitigate | Preview both employee and manager messages with explicit recipient IDs before sending; require user confirmation (per lark-im safety constraint) |
| T-03-05 | Elevation of Privilege | ReminderRegistration stub | accept | Phase 3 is client-side only; no server endpoint exists yet. Stub type defines future interface but has no runtime attack surface |
| T-03-06 | Spoofing | config.json managerId | mitigate | Validate managerId is non-empty string matching Feishu userID format before sending; log warning if invalid; never guess manager ID |
